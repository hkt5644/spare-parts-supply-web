# 수리부속 순환보급체계

정비 사용 → 중간 물류대대 정수 확인 → 중앙 물류 자동 청구 → 조달로 이어지는 보급 흐름을 가상 데이터로 시험하는 프로토타입입니다.

- 사이트: https://hkt5644.github.io/spare-parts-supply-web/
- 배포: GitHub main 브랜치에 올리면 GitHub Pages가 자동으로 다시 배포합니다.
- 데이터: Supabase에 저장됩니다. 이메일 로그인 링크로 로그인하고, 관리자가 정한 역할(정비부대·중간 물류대대·중앙 물류·조달·관리자)의 작업만 할 수 있습니다.
- 보안: 모든 테이블에 RLS를 켜서 역할을 받은 사용자만 조회할 수 있고, 변경은 역할을 검사하는 DB 함수로만 합니다.
- DB: schema.sql(테이블) → auth.sql(로그인·역할·업무 함수) 순서로 실행합니다.
- 모든 부대·품목·수량은 가상 데이터입니다.
